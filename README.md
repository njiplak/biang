# Kawakib - Basis

## Overview

Kawakib - Basis is a Laravel starter kit for Kawakib MVP.

## Key Selling Points

- **Trending Now (SA-focused)** — Real-time visibility into what's trending across South African social media
- **AI Recommendations** — Fast, low-cost idea generation for marketers to pitch internally
- **Brand Recognition** — Detect organic brand mentions via tags, comments, mentions, voice, and image signals

## Platform Focus

- TikTok
- Instagram

## Features

### Master

| Feature | Description |
|---------|-------------|
| Users | Manage system users who can access the platform |
| Roles | Define roles like Admin, Strategist, Read-only |
| Permissions | Define granular permissions for features |
| Platforms | Social media platforms (TikTok, Instagram, etc.) |
| Trend Categories | Categories to classify trends (fashion, food, travel, etc.) |
| Trend Types | Types of trends (hashtag, sound, topic) |
| Hit Types | Types of brand recognition signals (tag, comment, mention, voice, image) |
| Regions | Geographic regions for creator filtering (SA provinces/cities) |
| Asset Types | Types of content assets (creator-made, studio-produced) |
| Event Types | Tracking event types (qr_scan, utm_click, voucher_redeem, etc.) |
| Brands | Client brands being monitored on the platform |
| Creators | Social media creators/influencers to track |

### Operational

| Feature | Description |
|---------|-------------|
| Dashboard | Main landing page with KPIs and summary widgets |
| Campaigns | Marketing campaigns linked to brands |
| Trends | Trending topics/sounds/hashtags from TikTok & Instagram |
| Trend Examples | Example posts that showcase a trend |
| AI Ideas | AI-generated content concepts based on trends and brand context |
| Assets | Content pieces (posts, videos) tied to campaigns |
| Brand Recognition | Organic mentions of brand detected across platforms |
| Events | Tracking events from QR scans, UTM links, etc. |
| Reports | Top creators and top assets rankings |

### Settings

| Feature | Description |
|---------|-------------|
| API Keys | Store and manage third-party API credentials |
| Integration Config | Configure data pull settings |
| Job Schedules | Manage background job timing |

## User Roles

| Role | Description |
|------|-------------|
| Admin | Full access to all features and settings |
| Strategist | Manage brands, campaigns, trends, AI ideas, and view reports |
| Read-only | View dashboards, trends, creators, and assets only |

## Dashboard Widgets

- Trending Now on TikTok & Instagram
- AI Recommended content tiles
- Top Creators ranking
- Top Performing Assets
- Brand Recognition summary
- KPI Metrics (Total Reach, Engagement Rate, Actions)

## Filters

- Client (Brand) selector
- Period selector (1 Week, 2 Weeks, 30 Days, 6 Months)
